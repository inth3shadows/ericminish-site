terse 59% fewer tokens open

A proxy in front of MCP tool servers that losslessly compresses what they return. If a payload cannot be proven to reconstruct exactly, the original is forwarded untouched — lossless is the default, not a mode. Public, MIT, with a benchmark harness in the repo so you can measure the saving on your own tools.

RunEcho ~12 ms · 0 tokens open

Stops an agent from writing a call to a function your repo does not have — before the write lands, not after the build fails. It runs as a hook inside the agent loop, checking every edit against the symbols the code actually declares: no model, no network, no build, and a clean check costs no context at all. How often it is wrong is measured against dated git history rather than against a user clicking approve: 15.3% false positive, 33.7% premature, 51.0% a real unbacked reference.

testgraph journeys, not tests open

Given a diff, it answers which user journeys the change could have broken, and in what order to test them. Every comparable tool answers in tests and needs coverage from a previous run; testgraph walks a static call graph backwards from the changed lines, so it answers on a repo that has never run its suite. Recall-first on purpose: it would rather flag a journey that turned out fine than quietly drop one that broke.

harness 4 mechanical checks private

A one-man agent harness in two halves: a deterministic verdict on a code change, then the runtime that drives its own loop. The gate runs four stateless checks — the test suite, a symbol contract, staged secrets, reachable vulnerabilities — and a pass leaves the branch for a human to commit. There is no auto-commit, and the language model is never the judge.

Measurement

modelbench cost per solved task private

A personal benchmark that mines real bug-fix commits out of my own repositories and replays them against cheap models, several times each, so the gap between two models can be called noise or called real. It reports cost per solved task instead of a leaderboard score — and it publishes its own corrections: four figures it had already stated turned out to be a defective task dragging three capability tiers down at once.

Lodestone 5 of 10 at real scale open

Local retrieval over years of my own notes. Semantic search beat keyword search at 1,271 documents and lost to it at 57,500; the write-up leads with that. Includes a pre-registered kill gate, negative controls, and pooled blind judging.

The terminal

My whole working environment is a browser tab. A terminal multiplexer runs on a machine at home, fronted by a small web terminal, published through an identity-proxied tunnel — no port is open to the internet and no session starts without single sign-on. Opening the same address from a phone, a laptop or a borrowed machine attaches to the same live session, so work does not have a device attached to it.
