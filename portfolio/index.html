Agent infrastructure

terse 59% fewer tokens open

A proxy in front of MCP tool servers that losslessly compresses what they return. If it cannot prove a compressed payload reconstructs exactly, it forwards the original unchanged, so it is always lossless. MCP is the Model Context Protocol, the standard that connects tools to AI agents. The project is public under the MIT license, and the repository includes a benchmark harness so you can measure the saving on your own tools.

RunEcho ~12 ms · 0 tokens open

Stops an agent from writing a call to a function your repo does not have, before the edit is saved. It runs as a hook (a step the agent loop triggers automatically) and checks every edit against the functions and other symbols the code declares. It uses no language model, no network and no build, and a passing check adds nothing to the agent’s context. Its accuracy is measured against dated git history. Of the cases it flagged, 15.3% were false positives, 33.7% were premature (the code was added later), and 51.0% were references to something that did not exist.

testgraph names journeys at risk open

Given a diff, it answers which user journeys the change could have broken, and in what order to test them. Comparable tools answer with a list of tests and need coverage data from a previous run. testgraph walks a static call graph (a map of which code calls which) backwards from the changed lines, so it works on a repo that has never run its test suite. It is tuned to catch every journey that broke, so it will sometimes flag one that turned out fine.

harness 4 mechanical checks private

A single-developer agent harness in two parts: a fixed-rule verdict on a code change, and the runtime that drives its own loop. The gate runs four stateless checks: the test suite, a symbol contract, staged secrets, and reachable vulnerabilities. A pass leaves the branch for a human to commit. Nothing is committed automatically, and no language model makes the judgment.

Measurement

modelbench cost per solved task private

A personal benchmark that takes bug-fix commits from my own repositories and replays them against cheap models, several times each, so a gap between two models can be judged as noise or as a genuine difference. Its headline figure is cost per solved task. It also publishes its own corrections: four figures it had stated earlier were pulled down by one defective task that affected three capability tiers.

flight-recorder 11,179 sessions scored private

Scores each coding-agent session on two things, kept separate: what it cost, from the transcript, and how much of its code was still in the repository later, from git. Every average comes with a 95% confidence interval, and models are compared only on similar work, so a hard repository does not make a model look weak.

Lodestone 5 of 10 at full scale open

Local retrieval over years of my own notes. Semantic search beat keyword search at 1,271 documents and lost to it at 57,500, and the write-up starts with that result. The experiment set a kill gate in advance (a stated condition for stopping the project), and it also used negative controls (cases where the right answer is known to be nothing) and blind judging of pooled results.

Data and operations

Frostline 50,083 well records open

Spatial models over the public Michigan well record. Depth is predictable from location, with a Moran’s I of 0.393. Moran’s I measures how strongly nearby wells resemble each other, from 0 (no pattern) to 1 (strong). Yield scores 0.089. One promising target was dropped after it turned out to be about 96% a restatement of depth.

Origin Sentinel staged self-heal open

Origin-health detection for services reached through a tunnel (a Cloudflare connection that exposes a machine without opening ports). It catches the failure where the public edge looks healthy but the service behind it is down. It first shipped without write access and was given the ability to fix problems once its classifications held up in the field.

The terminal

My whole working environment is a browser tab. A terminal multiplexer runs on a machine at home, fronted by a small web terminal, published through an identity-proxied tunnel, so no port is open to the internet and no session starts without single sign-on. Opening the same address from a phone, a laptop or a borrowed machine attaches to the same live session, so work carries over between devices.
