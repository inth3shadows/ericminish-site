RunEcho

A Go guard layer for coding-agent sessions: symbol lookup, edit-scope contracts, and pre-commit checks that run before a change lands.

Its parser design turns on one question per language — whether a cheap masker would guess wrong. Rust gets a real grammar because a lifetime and a character literal are indistinguishable without parsing, and a wrong guess drops symbols silently.
