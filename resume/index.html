2025 — presentIndependentBuilt, shipped and run

Agent infrastructure

  • RunEcho checks each edit a coding agent makes, before the file changes, against the names the repository declares. On nine confirmed invented names it caught four. Each check takes about 12 ms, uses no model or network, and adds nothing to the agent’s context when it passes. Public, MIT license.
  • terse is a proxy that compresses AI tool output without losing information: 59% fewer tokens on GitHub API payloads, its best case. A replay of my own sessions, priced at what each call was billed, put it at 23% of MCP result cost and under 1% of the bill, and decided which two tools to keep working on. Public, MIT license.
  • testgraph reads a diff and names the user journeys the change could have broken. Similar tools list tests and need coverage data from an earlier test run; testgraph works on a repository whose tests have never been run. Public, MIT license, published on PyPI.
  • modelbench benchmarks models on real bug-fix commits mined from my own repositories. Each model runs each task three times, and models are scored on cost per solved task. Its write-up lists the earlier figures that were later corrected.
  • harness gives each code change a verdict from four rule-based checks: the tests, a symbol contract, a credential scan and a vulnerability scan. No model takes part in the judging, and nothing is committed automatically. Its agent runtime so far uses read-only tools.
