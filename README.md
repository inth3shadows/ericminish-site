# ericminish.com

**I build the infrastructure AI agents run on, and the data work that runs on top of it.**
This is the source of [ericminish.com](https://ericminish.com): hand-written static HTML,
no build step, JavaScript only for the Frostline maps, served from my own homelab.

Start with the work (the same five the home page leads with):

- **[codegraph correctness](https://ericminish.com/portfolio/codegraph/)**: checks the open-source codegraph call graph against each language's type checker and files the differences upstream ([graph-assay](https://github.com/inth3shadows/graph-assay), [codeshot](https://github.com/inth3shadows/codeshot)).
- **[terse](https://github.com/inth3shadows/terse)**: compresses what an agent's tool servers return in a form that always restores exactly; 59% fewer tokens on its best case.
- **[flight-recorder](https://ericminish.com/portfolio/flight-recorder/)**: scores each coding-agent session on cost and on how much of its code survived (private repo; case study only).
- **[RunEcho](https://github.com/inth3shadows/runecho)**: checks each agent edit against the names the repository declares, before the file changes.
- **[secret-broker](https://ericminish.com/portfolio/secret-broker/)**: lets agents use API keys without receiving them (private repo; case study only).

More case studies, including [testgraph](https://github.com/inth3shadows/testgraph), are under [/portfolio](https://ericminish.com/portfolio/).

## Hosting

Served as static files by Caddy in a self-hosted container behind a Cloudflare
tunnel. Host, container, document root and the deploy runbook (including its
gotchas) are kept in the private homelab knowledge base under
`host-ericminish.com`, not here: this repo is public.

## Structure

- `index.html` — home
- `about/` — background and working style
- `portfolio/` — case studies and selected work
- long-form case studies, one directory each: `portfolio/codegraph/`, `portfolio/terse/`,
  `portfolio/runecho/`, `portfolio/testgraph/`, `portfolio/harness/`, `portfolio/modelbench/`,
  `portfolio/lodestone/`, `portfolio/frostline/`, `portfolio/origin-sentinel/`,
  `portfolio/llm-gateway/`, `portfolio/flight-recorder/`, `portfolio/knowledge-base/`,
  `portfolio/secret-broker/`
- `writing/` — long-form posts; index, Atom feed and reading times generated by `tools/gen-writing.py`
- `homelab/` — practical lab notes
- `status/` — what is current right now
- `contact/` — direct contact path
- `resume/` — résumé page and its content-addressed PDF
- `inbox-triage/` — public description and privacy policy for inbox-triage, a personal Gmail triage tool
- `tools/` — build-time helpers and checks (`gen-writing.py`, `check-pages.py`, `check-live.py`, `regen-deploy.sh` and others), not shipped to the live site
- `assets/` — shared CSS and SVG assets

Contractor work is pointed at The Frostline Co. by link, not by a services
page on this site.

## Deploy

Host, container, document root and the deploy runbook (including its
gotchas) are kept in the private homelab knowledge base under
`host-ericminish.com`, not here: this repo is public.

1. Back up the current live tree.
2. Copy this folder's site contents *into* the live document root (never swap
   the directory itself; the runbook says why).
3. Verify locally inside the container at `http://127.0.0.1:8080`.
4. Verify publicly through `ericminish.com`.
