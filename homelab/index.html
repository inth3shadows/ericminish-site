Why It Matters

Separation helps

The useful part of the lab is not the node count. It is having clear separation between boxes, services, and public surfaces so changes are easier to reason about and failures are easier to isolate.

Uptime Kuma is the monitoring piece I most want to surface here. A better next version of this page would turn the hardware/status block above into a real status view instead of a static sketch.
