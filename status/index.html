Day job

Integration and data-pipeline engineering: CRM workflow automation, ingestion services and scheduled jobs on managed cloud infrastructure, and warehouse-backed reporting behind access control. One of those services is LLM-assisted — it scores call transcripts against a rubric, deterministic checks first, human review after, with the model never given the last word. Categorical on purpose: the interesting part is the shape of the work, not whose it is.

terse

A lossless compression proxy for MCP tool output — 30 to 50 percent fewer tokens, with the original forwarded untouched whenever a perfect round trip cannot be proven. Recent work has been on the security edges: credentials must not survive a cross-origin redirect, and a config generator that measures performance is never allowed to overwrite a safety setting. Case study.

Knowledge graph

A personal knowledge base on Postgres that agents write into by proposal only, with every proposal reviewed before it lands. This quarter it moved off local embeddings onto a sidecar — production image down from 2.14 GB to 442 MB — and shed half its tool surface, because response bytes turned out to be the real constraint, not tool count.

Frostline

Spatial modeling over fifty thousand Michigan well records, and the contractor-intake business built around it. Depth is predictable from location; yield is not. Both of those are useful to know, and the second one took longer to accept.

Homelab

Ten machines under Proxmox carrying real routing, monitoring, and backup — plus the recurring lesson that ordering and detection are not controls. A VPN-bound workload gets pinned to the tunnel interface by name, because restarting things in the right order only works until it doesn't.
