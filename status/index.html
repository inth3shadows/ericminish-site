Projects in progress

Day job

I am a Senior AI Engineer at a company whose sales, operations and partner teams run on software I build: a console that gathers a consultant’s tools in one place, a partner portal, a lead-intake API for partners, Python services that sync call activity and clean CRM records, monitoring, and a call-compliance auditor. Two of these services use a language model as a judge; in the call auditor, rule-based checks run first and a person reviews every result.

As of 4 November 2026 that work spans 60 repositories, and 29 of them changed in the last 30 days. I wrote about 95% of the commits since September.

codegraph

Last change 3 November 2026 · 17 pull requests merged in the last 30 days · merged changes

codegraph is an open-source tool that maps which functions call which, for coding agents. I check its map against type checkers and against freshly built indexes and send fixes upstream.

Recent fixes, 29 October to 3 November: index updates that drifted from a fresh build of the same commit, and TypeScript variance annotations. Case study.

terse

Last change 30 October 2026 · 54 pull requests merged in the last 30 days · merged changes

terse compresses the output of MCP tools (the tools AI agents call) in a form that always restores exactly. In my own sessions it removes 23% of what MCP results cost, under 1% of the whole bill.

Late October: fixes from a red-team review that found 37 problems (28 October), and a decoder that treats an integer longer than Python’s 4,300-digit limit as plain text instead of crashing. Case study.

RunEcho

Last change 1 November 2026 · 34 pull requests merged in the last 30 days · merged changes

RunEcho checks each edit a coding agent makes against the names the repository declares, before the file changes.

Late October: a setting that blocks a flagged edit instead of asking (28 October), and blocking by default under Cursor, which does not enforce the ask step (30 October). Case study.

flight-recorder

Last change 21 October 2026 · 10 pull requests merged in the last 30 days

flight-recorder scores each coding-agent session on what it cost and how much of its code was still in the repository when it was last scored.

21 October: an evidence layer that rebuilds each request the agent sent from its transcript, and checks that every MCP tool call in the transcript appears in the wire log terse recorded. Case study.

modelbench

Last change 3 November 2026 · 39 pull requests merged in the last 30 days

modelbench replays real bug-fix commits against cheaper models and reports the cost per solved task.

Late October: a blinded sample for judging RunEcho’s own checker. Flagged lines and clean lines are mixed, the labels are kept in a separate file, and two models judge each item. Case study.

testgraph

Last change 30 October 2026 · 10 pull requests merged in the last 30 days · merged changes

Given a code change, testgraph names the user journeys it could have broken, from a static call graph, so it works on a repository that has never run its tests.

30 October: CI now runs its verify step end to end with pytest and its tracing plugin, which records what each journey’s tests execute, so the static selection can be scored against what ran. Case study.

secret-broker

Last change 3 November 2026 · 17 pull requests merged in the last 30 days

secret-broker lets coding agents use credentials without receiving them, and writes a receipt for every call to a log that shows any later edit.

3 November: it can now rotate a credential it created, through a write route on the vault service, and only after a person approves the request. Case study.

harness

Last change 3 November 2026 · 5 pull requests merged in the last 30 days

harness decides whether an agent’s code change is acceptable with four fixed checks. No language model takes part, and nothing is committed automatically.

The gate and the role runtime are done. Next is a set of tools that can write files, so the loop that produces changes runs inside harness. Early November: fixes to its mutation-testing tool. Case study.

Knowledge base

Last change 30 October 2026 · 49 pull requests merged in the last 30 days

Long-term memory for my coding agents. Agents can only propose an entry, and an AI reviewer approves, edits or rejects each proposal.

Late October: each session now records what it set out to do and how it ended, and the status command warns when the reviewer runs different code from the deployed tree. Case study.

soundings

Last change 4 November 2026 · 38 pull requests merged in the last 30 days

A store of US county economic data that keeps every published version of each number, so a backtest uses only the figures known at the time.

30 October: county employment from the Bureau of Labor Statistics’ quarterly census (QCEW) became the default employment input for its detector.
