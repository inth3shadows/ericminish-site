Current work

What I am working on right now.

Updated September 2026.

Active

Day job

Integration and data-pipeline engineering: CRM workflow automation, ingestion services and scheduled jobs on managed cloud infrastructure, and warehouse-backed reporting behind access control. One of those services uses a language model to score call transcripts against a rubric. Fixed rule-based checks run first, and a person reviews the result afterward, so the model does not make the final decision.

terse

A compression proxy for MCP (Model Context Protocol, the standard that connects tools to AI agents) tool output. It cuts tokens by 59 percent without losing information, and it forwards the original output unchanged whenever it cannot prove the compressed version restores exactly. Recent work has been on security: credentials must not follow a redirect to another site, and a config generator that tunes for speed is not allowed to overwrite a safety setting. Case study.

testgraph

Given a code change, it names the user journeys the change could have broken. It traces a static call graph (a map of which code calls which) instead of reading a test coverage report, so it works on a repository that has never run its tests. It was recently made public and published on PyPI. Current work compares the journeys it selected against what running them found, so its miss rate can be reported as a number. Case study.

harness

An agent harness that judges a code change with four fixed checks. No language model takes part in the judgment, and nothing is committed automatically afterward. The loop that drives it still runs inside someone else’s runtime. The current build moves that loop in, with tools that can write files running under defined isolation rules. Case study.

Knowledge graph

A personal knowledge base on Postgres that agents write into by proposal only, with every proposal reviewed before it lands. This quarter it moved its embeddings (the numeric text representations used for search) into a separate sidecar service, which cut the production image from 2.14 GB to 442 MB. It also dropped half its tools, because the size of each response mattered more than the number of tools.

Frostline

Spatial modeling over fifty thousand Michigan well records, and the contractor-intake business built around it. Well depth can be predicted from location. Well yield (how much water a well produces) cannot.

Homelab

Ten machines under Proxmox (a server virtualization platform) running live routing, monitoring and backups. A workload that must go out through a VPN is bound to the VPN interface by name, because starting services in the right order does not guarantee it.
