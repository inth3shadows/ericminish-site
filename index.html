Recent work

terse

A proxy between my AI agent and the servers that run its tools. It compresses the tool output so the model reads fewer tokens. When it cannot prove the compressed version decodes back exactly, it sends the original output. On nine GitHub API responses totalling 365,144 tokens, the compressed output had 59% fewer tokens than the raw JSON.

59% fewer tokens public · MIT
testgraph

Given a code change, it names the user journeys (sequences of actions a user takes, such as “claimant submits a signed form”) the change could have broken. It walks a static call graph (a map of which code calls which) backwards from the changed lines. Similar tools need coverage data (a record of which code an earlier test run executed). testgraph works on a repository whose tests have never been run.

no prior test run needed public · MIT
RunEcho

Stops an AI agent from writing a call to a function that does not exist in the repository. Before the file is changed, it checks the edit against the function, type and constant names the code declares. The check takes about 12 ms and uses no model and no network. When the check passes, it adds nothing to the agent’s context.

0 context tokens public
modelbench

Replays real bug-fix commits from my own repositories against lower-cost models, three times per model by default, and reports the cost per solved task. On fifteen tasks, the small tier solved 10 at $0.51 per solved task and the large tier solved 15 at $2.09. The write-up lists the earlier figures that had to be corrected.

$0.51 vs $2.09 per solve private
Lodestone

Local search over my own working notes: Claude Code session transcripts, a ChatGPT export, planning documents and repository markdown. On paraphrased questions, its search by meaning beat keyword search over 1,222 chunks (short passages cut from the notes) and lost to it over the full collection of 57,562 chunks. I published both results. On ten recall questions asked against the full collection, the default setup returned something useful in its top three results for five.

5 of 10 useful lost at full scale
