Recent work

terse

A proxy between my AI agent and the servers that run its tools. It compresses the tool output so the model reads fewer tokens (the units a model reads and is billed by). When it cannot prove the compressed version decodes back exactly, it sends the original output.

59% fewer tokens than raw output public · MIT
testgraph

Given a code change, it names the user journeys the change could have broken. Similar tools need coverage data (a record of which code an earlier test run executed). This one works on a repository whose tests have never been run.

no prior test run needed public · MIT
RunEcho

Stops an AI agent from writing a call to a function that does not exist in the repository. The check runs before the file is changed and takes about 12 ms. It uses no model and no network, and when the check passes it adds nothing to the agent’s context (the text the model reads).

0 context tokens public
modelbench

Replays real bug-fix commits from my own repositories against lower-cost models, several times each, and reports the cost per solved task. The write-up lists the earlier figures I had to correct.

cost per solved task private
