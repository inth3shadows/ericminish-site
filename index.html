Recent work

codegraph correctness

codegraph is an open-source tool that maps which functions call which and serves that map to coding agents. I check its map against each language’s own type checker and against freshly built indexes, reduce each difference to the smallest code that shows it, and file it upstream. Of 111 issues filed, the maintainer closed 81 as completed, and 17 of my pull requests were merged.

17 PRs merged upstream public fork · MIT
terse

A proxy between my AI agent and its tool servers that compresses what they return in a form that always restores exactly. Its best case, GitHub API payloads, is 59% fewer tokens. A replay of my own sessions, priced at what each call was billed, put it at 23% of what MCP results cost and under 1% of the whole bill, so I narrowed the work to the two tools that carry the saving.

23% of MCP cost public · MIT
flight-recorder

Scores each coding-agent session on two things, kept separate: what it cost, from the transcript, and how much of its code was still in the repository when it was last scored, from git. A session is re-scored until it is seven days old. It has scored 11,179 sessions. Every average comes with a 95% confidence interval, and models are compared only on similar work.

11,179 sessions scored private
RunEcho

Checks each edit a coding agent makes, before the file changes, against the function, type and constant names the repository declares, so a call to something that does not exist is caught. On nine confirmed invented names it caught four. Each check takes about 12 ms, uses no model and no network, and adds nothing to the agent’s context when it passes.

0 context tokens public
secret-broker

Lets coding agents use API keys without receiving them. The broker makes the call itself and returns the cleaned-up result, and every call writes a receipt to a hash-chained log, so a later edit to the log shows. 2,568 receipts over six months check out intact.
